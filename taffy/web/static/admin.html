向量模型（知识库检索用）

这是给知识库检索用的，跟上面聊天 / 图片那两套没关系。
检索是三路一起用的：词匹配管精确词（STM32F103、I2C、IEEE754 这种）； 英文检索词会把中文问题翻成英文关键词去查英文教材（用上面那个「检索翻译模型」）； 向量管语义——换个说法、近义表达只有它认得出。
英译和词匹配那两路不要钱，所以这一路留空也能用，配上只是更准。
任何 OpenAI 兼容的 /embeddings 接口都能用。
索引维度按 EMBED_DIM 校验（当前 ? 维）， 对不上会直接报错。改完要重启服务才生效，而且会重新向量化一遍全库。
